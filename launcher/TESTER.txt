Nightreign Invasions - tester build (not for release)
=====================================================

Both players must use the same package (the same invasion.dll); mixed versions are not supported.

No settings are needed: every map is a two-region map (Mountaintop + Rotted Woods); every player
hosts its own expeditions (other mod players can invade
them) and "Invasion" in the Roundtable Hold joins another player's expedition. The launcher's
"Debug log" box makes the mod log everything (for bug reports); off, the log is short.

Optional test settings are in test-settings.toml next to the launcher (all false plays normally):

  team-test    Solo tests only (leave false in a two-player test).
  slow-time    Both players the same value; the host's counts. Clocks run ten times slower.
  full-sync    Invader (on by default). Ask the host for its full world state. false only for tests.
  loot-test    Logging only. What lies on the ground, every pickup and equipment dialog.
  no-host      Test. Your own expedition opens no host session, so nobody can invade you. Only for
               checking item pickup; back to false afterwards.
  test-level   Test. A number (0 = off, up to 15): your own expedition sets your level to it 5 s
               after the start, for faster boss tests. Not while invading.
  ally         Test, the joining player only. true: "Invasion" in the Roundtable Hold joins the
               host's running expedition as an ally (a squad member: no red colour, the host's
               team, no invasion reward) instead of as an invader. The host needs no setting; up
               to two allies per host (squad of three), and invaders can still come on top.
  party        Test. A code (1..999, 0 = off), the same for every player of the squad; not needed when
               you type the same password in the game's own expedition menu (the password is used
               then). With either, "2 players" / "3 players" works without FromSoftware's servers: the
               first player to start it hosts and goes into the expedition at once; the others start
               the same expedition with the same password and wait in the Roundtable Hold ("Waiting
               for the squad's host...") until the host is in the field, then join it automatically.

Every expedition map has two Shifting Earth regions: the Mountaintop and the Rotted Woods (the map
screen shows both), and more HP flask charges at the start (at least 7 with every church).

The closing circle has no rain: no falling rain, no rain damage, no rain sound, no notice when it
starts to move and no border, near or far; your character and the health bar keep their colours
outside it, and sites of grace outside it stay usable. The circle still closes as usual (the map
screen shows it) and the night boss comes as in the game.

The map screen shows the Rotted Woods' own markers on its part of the map: the place of the
treasure map and, once you have picked it up, the tree with the reward.

An invasion may end on a stuck loading screen or a crash; quit the game if it hangs.

The mod writes its log to work/native/invasion.log (its first lines list the settings it used).
Send that file after each test session.

Launcher buttons: "Backup" copies your saves into backups/<date_time>/ next to the launcher (only
copies, never deletes or overwrites); "Help" explains every button; the language box switches the
window between English, Polski, Deutsch, Français and Español (remembered in language.txt).
