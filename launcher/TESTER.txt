Nightreign Invasions - tester build (not for release)
=====================================================

Both players must use the same package (the same invasion.dll); mixed versions are not supported.

No settings are needed: every player hosts its own expeditions (other mod players can invade
them) and "Invasion" in the Roundtable Hold joins another player's expedition. The launcher's
"Debug log" box makes the mod log everything (for bug reports); off, the log is short.

Optional test settings are in test-settings.toml next to the launcher (all false plays normally):

  team-test    Solo tests only (leave false in a two-player test).
  no-rain      Both players the same value. The rain outside the circle does no damage.
  slow-time    Both players the same value; the host's counts. Clocks run ten times slower.
  full-sync    Invader (on by default). Ask the host for its full world state. false only for tests.
  loot-test    Logging only. What lies on the ground, every pickup and equipment dialog.
  map-test-control  Experiment (host or solo). Your own expedition is always one of the game's own
               Mountaintop maps, drawn by the game as usual: a control for two-regions.
  two-regions       Experiment (host or solo). Your own expedition gets one map with two Shifting
               Earth regions: the Mountaintop and the Rotted Woods (the map screen shows both), and
               more HP flask charges at the start (at least 7 with every church). An invader joining
               you must have two-regions on as well. Turn on one map test only, and back to false
               afterwards.
  no-host      Test. Your own expedition opens no host session, so nobody can invade you. Only for
               checking item pickup; back to false afterwards.

An invasion may end on a stuck loading screen or a crash; quit the game if it hangs.

The mod writes its log to work/native/invasion.log (its first lines list the settings it used).
Send that file after each test session.

Launcher buttons: "Backup" copies your saves into backups/<date_time>/ next to the launcher (only
copies, never deletes or overwrites); "Help" explains every button; the language box switches the
window between English, Polski, Deutsch, Français and Español (remembered in language.txt).
